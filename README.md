# PlayStation Gaming Wall Art

A DIY gaming wall art project made from a PlayStation game case, a printed game cover, a GIF player, and 3D-printed parts.

This project turns a simple game case into a unique gaming decoration with a small display that can play your favorite GIFs.

## Features

* PlayStation game case design
* Custom printed game cover
* Small GIF player with display
* 3D-printed disc holder
* 3D-printed action figure holder
* Custom printed game disc
* A4 deep picture frame
* Custom printed background
* Easy to build
* Low-cost project

## What You Need

* 1× PlayStation game case
* 1× Printed game cover — 270 × 166 mm
* 1× Printable game disc
* 1× GIF player
* 1× A4 deep picture frame
* 1× Printed game background
* 1× 3D-printed disc holder
* 1× 3D-printed action figure
* Double-sided tape
* Glue

## GIF Player

The GIF player is based on an ESP32 and a small display.

You can find the complete GIF player project, including the code, PCB files, wiring, and other files, in my previous GitHub project.

## 3D Print Files

All the 3D-printable files for this project are included in this repository.

You can download the files, print the parts, and build your own gaming wall art.

## Assembly

The project is made in a few simple steps:

1. Print the game cover.
2. Prepare the PlayStation game case.
3. Assemble the printed cover and game case.
4. Prepare the A4 picture frame.
5. Cut the display opening in the back of the frame.
6. Attach the printed background.
7. Install the GIF player.
8. Add the 3D-printed parts.
9. Assemble everything together.
10. Add your favorite game disc and action figure.

## Cost

The project is designed to be low-cost and easy to build.

The GIF player itself costs less than **$6** to build, depending on the components and prices in your area.

## Customize Your Project

You can use any PlayStation game you like.

Change the game cover, background, disc, GIFs, and action figure to create your own custom gaming wall art.
